# PBO TO LOWERCASE
Bourne-Again shell script which converts .pbo filenames to lowercase.
Mods which you include in your mod parameter when launching an Arma3 server must have their .pbo files in lowercase, otherwise the server won't start.
This script loops over the mod directories starting with '@' and converts .pbo files filenames to lowercase.
# Usage:
1. Copy the script into a local text file. Make sure to locate it in the same directory where your mod files are.
2. Add execution privileges to the text file with "sudo chmod +x"
3. Run the script
# Have fun.
